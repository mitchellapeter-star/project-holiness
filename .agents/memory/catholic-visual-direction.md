---
name: Catholic visual direction
description: The current light stained-glass visual character to preserve when extending Project Holiness.
---

Preserve the luminous Catholic direction: warm ivory and parchment surfaces, forest green, muted gold, clearly visible stained-glass color, serif typography, and restrained sacred ornament.

**Why:** The user found the dark chapel treatment too dark but explicitly liked the stained glass and asked to return to green and gold.

**How to apply:** Keep the interface bright and readable. Use stained glass prominently enough to recognize, especially in banners and background accents, but soften it behind content. Avoid dominant dark sacred-art backgrounds.
